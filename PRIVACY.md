# Privacy Policy: AI Base (ki_erp_ai_base)

AI Base is free, open-source software that runs on your own Frappe or ERPNext site. kalvyai does not
operate a service for it and collects no data from it.

- **Data stays on your site.** Provider settings, encrypted API keys and usage logs are stored in your
  site's database only.
- **AI providers.** When an app calls AI Base, the prompt and any attached files are sent only to the
  AI provider(s) you configure (for example OpenAI, Anthropic, Google), using your own API key. Their
  handling of that data is covered by their own terms and privacy policies.
- **No telemetry.** AI Base sends no analytics, tracking or usage data to kalvyai or anyone else.
